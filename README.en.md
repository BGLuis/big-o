# 📖 About

**Big O Viz** is an interactive educational sandbox platform designed to help programming students understand classical algorithms and data structures through animations and step-by-step executions.

The application includes dedicated renderers for linear, linked, hierarchical, stack, queue, hash map, and graph structures, along with sorting algorithm visualizations featuring timeline playback controls (play, pause, step forward, and step back).

# 📋 Motivation

The motivation for creating this project arose from a conversation with Professor Ariane (Professor at PUC Minas), after which I decided to create a way to help students visualize data structures.

# 💻 Getting Started

### Requirements

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/) 11.13.0

### Installation

1. Clone the repository:

   ```sh
   git clone https://github.com/BGLuis/big-o.git
   ```

2. Enter the project directory:

   ```sh
   cd big-o
   ```

3. Install dependencies and start the development server:

   ```sh
   npm install
   npm start
   ```
